1) What is the purpose of having an individual handler function for each exception/interrupt? (i.e., if all exceptions/interrupts were delivered to the same handler, what feature that exists in the current implementation could not be provided?)
The purpose is so that the kernel can determine which trap occurred and apply specific handling policies based accordingly. It allows the the kernel to push
the correct trap number into the trapframe and initiate different logic such as the page fault handler, syscall handler, breakpoint monitor etc. You would also lose the ability to
selectively expose certain traps while in user mode.
